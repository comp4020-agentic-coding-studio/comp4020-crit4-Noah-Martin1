# Process overview

## What I built

**Instrument Kit** — six instruments in one tuning, and a loop to layer them
into. Harp and guitar are Karplus–Strong; marimba and bells one
struck-resonator synthesis differing only in partial ratios. Nothing is sampled. One chord exists at a time and every instrument is tuned to it, so no
combination can be wrong.

## The moments that mattered

### Being the ear

> the bass isnt right - make it more like a guitar - its too twangy

The agent cannot hear what it builds, so every real correction came from
listening. When building a sound design website its important that its possible for the user to create or simply play pleasant music using the tools provided. In building the instrument kit, I realised through playing around with the instruments that it was difficult to create something that sounds good (also having limited music creation skill). So I prompted claude to create an example soundtrack that uses the instruments and I tweaked it so it sounded better. This way the user can be inspired by the capability of the website.
